BACKLOG GA KILL (BGK) - INSTRUCCIONES PARA WINDOWS

1. Clona o descarga el repositorio.
2. Abre la carpeta del proyecto desde Android Studio.
3. Selecciona JDK 17 para Gradle.
4. Instala Android SDK 35 si Android Studio lo solicita.
5. Copia local.properties.example como local.properties.
6. Deja que Android Studio escriba sdk.dir y completa solo las claves opcionales
   que quieras usar. No compartas este archivo.
7. Sincroniza Gradle, conecta un móvil o crea un emulador y pulsa Run.

También puedes generar un APK de depuración con:

    .\gradlew.bat assembleDebug

El resultado estará en:

    app\build\outputs\apk\debug\app-debug.apk

No publiques un APK compilado con credenciales personales. Consulta README.md
para configurar Steam, PlayStation, Nintendo, RAWG y TheGamesDB.
